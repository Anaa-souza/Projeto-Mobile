# 🩺 Healthcare+

### Sua saúde organizada em um só lugar!

---

## 📌 Sobre o projeto

O **Healthcare+** é um aplicativo mobile desenvolvido como projeto acadêmico no curso Técnico em Desenvolvimento de Sistemas do SENAI. A proposta é facilitar a organização de consultas médicas por meio de uma interface simples, intuitiva e acessível.

A aplicação foi planejada para permitir que os usuários realizem seu cadastro, acessem suas contas, visualizem suas consultas e gerenciem seus agendamentos em um só lugar.

Nosso objetivo é utilizar a tecnologia para tornar o acompanhamento de consultas mais prático e organizado.

## 🎯 Objetivo

Desenvolver um aplicativo mobile que auxilie os usuários no gerenciamento de consultas médicas, oferecendo recursos que facilitem o acesso às informações e a organização dos agendamentos.

## ✨ Funcionalidades

- 🔐 **Login:** acesso à conta do usuário.
- 📝 **Cadastro:** criação de uma nova conta.
- 📅 **Agendamento de consultas:** organização dos compromissos médicos.
- 📋 **Minhas consultas:** visualização dos agendamentos.
- 👤 **Perfil do usuário:** acesso às informações pessoais.
- ✏️ **Gerenciamento de consultas:** possibilidade de organizar os agendamentos conforme as funcionalidades implementadas.
- ✅ **Validação de dados:** verificação das informações preenchidas.
- ⚠️ **Mensagens de feedback:** avisos para orientar o usuário durante a utilização.
